# Simple Calculator

A console-based calculator developed using Java.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Continuous calculations
- Input validation
- Division by zero handling

## Technologies Used
- Java 21
- Eclipse IDE
- Git and GitHub

## How to Run
1. Clone this repository.
2. Import the project into Eclipse.
3. Open `Calculator.java`.
4. Run the program.
